# SMS Spam Detection using Machine Learning
Overview
This project is an end-to-end Machine Learning model that classifies SMS messages as **Spam or Not Spam** using Natural Language Processing techniques.

# Dataset
- SMS Spam Collection Dataset
- Contains labeled messages:
- Not Spam (legitimate messages)
- Spam (unwanted messages)

# Workflow
- Data cleaning and preprocessing  
- Label encoding (spam = 1, not spam = 0)  
- TF-IDF vectorization for text conversion  
- Model training using Naive Bayes classifier  
- Model evaluation using accuracy and confusion matrix  

# Model Used
- Multinomial Naive Bayes

# Results
- High accuracy achieved in classifying spam vs not spam messages

# Stack
- Python  
- Pandas  
- Scikit-learn  
- NLP (TF-IDF)

# Example Prediction
Input: "Congratulations! You won a free iPhone"  
Output: SPAM

# Key Learning
- End-to-end ML pipeline  
- NLP text processing  
- Feature extraction using TF-IDF  
- Model evaluation techniques
